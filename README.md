# カテーテル室 医療材料ダッシュボード

循環器内科カテーテル室で使用される医療材料の使用実績データ(模擬)を可視化するダッシュボードです。オフラインで動作する単一ページアプリケーション(HTML/CSS/JavaScript、外部通信なし)として実装しています。

## 公開ページ

GitHub Pagesで公開しています。`index.html` を開くと閲覧できます。

## 構成

- `index.html` — ページ本体(6タブ構成のUI)
- `app.js` — 集計・描画ロジック(Chart.js使用)
- `data.js` — 集計済みデータ(ビルド成果物。元データから生成)
- `tools/rebuild_ablation_cases.js` — アブレーション症例を患者単位の現実的な構成で再生成するスクリプト
- `tools/add_2025_cases.js` — 2025年のPCI・植込みデバイス症例を患者単位で追加するスクリプト
- `tools/add_waste_scenario.js` — シナリオ「A病院は償還対象材料の破棄・過剰使用が多く、他施設より材料コストが高い」を適用するスクリプト
- `tools/recompute.js` — 上記スクリプト共通の派生集計(症例・概観・ベンチマーク・メーカー集計)の再計算処理

データ生成の実行順: `rebuild_ablation_cases.js` → `add_2025_cases.js` → `add_device_benchmark.js` → `add_waste_scenario.js`
- `tools/add_device_benchmark.js` — 施設B〜Eのデバイス方式構成・材料使用量・新規方式の導入時期を生成するための施設プロファイル(係数)を data.js に書き込むスクリプト
- `chart.umd.min.js` — [Chart.js](https://www.chartjs.org/)(MITライセンス、ローカル同梱)

## タブ構成

画面右上の「対象年」で、全期間または年(2023〜2026年)を指定できます(在庫情報タブを除く全タブに反映)。年によってデータのない処置があり、その場合は画面上部に表示し、処置内容の選択肢からも除外します。

0. **経営サマリー**(初期表示) — 他施設比較を踏まえた経営層向けの要約。結論(3行、自動生成)、主要指標(年間材料償還額・1症例あたり材料償還額の他施設中央値比と順位・破棄破損損失・買取在庫・PFA比率)、処置別の他施設比較(中央値比・順位・ファンネルプロットによる統計的判定・前年比)、改善余地の年間インパクト(差益率改善・破棄削減・在庫圧縮・使用量の差)、材料区分別パレート図、経営判断が必要な事項(自動抽出)。差益率の改善幅と破棄削減目標はサイドバーで変更できる想定値です。
1. **データ概観** — データベースに含まれる症例数・処置内訳・在庫区分・メーカー内訳などの記述統計。処置内容フィルター付き。
2. **他施設ベンチマーク** — 自施設(A病院)と、統計的に生成した模擬5施設(B〜E病院)との比較。1症例あたり材料償還額・機材点数・症例構成比の比較、自施設のポジショニング表示、類似施設の判定、1症例あたり材料使用量(ステント・バルーン・ガイドワイヤー本数、イメージング・止血デバイス・高密度マッピング使用率等)の比較、ファンネルプロット(症例数を考慮した材料費の外れ値判定)、新しい方式(PFA・OCT・リードレス・S-ICD)の導入推移の比較、主要デバイスの多様性(方式構成・採用製品数)の施設間比較。
3. **ディーラー・メーカー市場戦略** — メーカー別シェア、月別取扱額推移、施設別メーカー浸透度、材料カテゴリ別の市場集中度(HHI)分析。処置内容フィルター付き。
4. **在庫情報** — RFID棚在庫を模したアイテム別の在庫状況(定数・現在庫・充足率・週間使用予測・欠品リスク)。
5. **デバイス多様性** — 同じ用途のデバイスの方式別の使い分け(例: アブレーションカテーテルの高周波/クライオバルーン/ホットバルーン/パルスフィールド)を、構成比・四半期推移・製品一覧で表示。方式は品名・規格から自動分類し、自施設で実績のない主な方式も「実績なし」として表示。

## 重要な注意事項

- 本ダッシュボードのデータは、自施設(A病院)分を含めすべて**模擬データ**です。実在の医療機関・患者の情報ではありません。
- 「他施設ベンチマーク」の施設B〜E、および「在庫情報」の在庫数量・週間予測は、A病院のデータを統計的に加工して生成しています。
- アブレーション症例(2023年1月〜2026年3月)は、患者単位の現実的なカテーテル構成を想定して生成したものです(`tools/rebuild_ablation_cases.js`、固定シードで再現可能)。1症例日=患者1人とし、適応(心房細動・発作性上室頻拍・心房粗動・心室頻拍等)と治療方式(高周波/クライオバルーン/ホットバルーン/パルスフィールド)に応じて、3Dマッピングシステム(CARTO/EnSite)と対応する診断カテーテル・シース類を割り当てています。治療用カテーテルは1本が基本で、バルーン・PFA症例の一部のみ高周波カテーテルで追加焼灼を行います。PFAは2024年10月以降に導入され、比率が段階的に上昇する想定です。追加製品の償還価格は本データセットの価格水準に合わせた模擬値です。
- 「他施設ベンチマーク」の主要デバイスの多様性比較では、施設B〜Eの方式構成・採用製品数は、A病院の実績に施設特性(大学病院・心臓血管センター等)を反映した係数を適用して算出した模擬値です(係数は `tools/add_device_benchmark.js`)。
- アブレーションの1症例あたり材料償還額(施設B〜E)は、アブレーションカテーテルの方式構成・追加焼灼率と整合するよう画面側で算出しています: 「カテーテル以外の材料費(A病院と同水準と仮定)+ カテーテル本数/症例(A病院の本数+各施設とA病院の追加焼灼率の差)× 方式構成で加重した平均単価(方式別単価はA病院の実績平均)」。高額な方式(PFA等)の比率や追加焼灼率が高い施設ほど償還額が高くなります。
- 1症例あたり材料使用量の比較(施設B〜E)は、A病院の実績値に施設特性を反映した係数を乗じた模擬値です(使用率は100%上限)。新しい方式の導入推移(施設B〜E)は、A病院の推移を施設ごとの導入時期の差(四半期)だけずらし、方式構成の係数を適用した模擬値です(係数はいずれも `tools/add_device_benchmark.js`)。
- **シナリオ(`tools/add_waste_scenario.js`)**: A病院は「償還対象材料の破棄・過剰使用が多く、他施設より材料コストが高い」病院として設定しています。PCIでガイドワイヤー・バルーンの多めの開封、マイクロカテーテル・IVUSの追加使用、サイズ違いによるステント・バルーン・IVUSの開封後破棄、植込みデバイスでリードの破棄(CRTは左室リード留置困難による交換)を確率的に加えています(アブレーションは対象外)。施設B〜Eは中央値がA病院の加工前の水準になるよう調整し、加工後も固定しています。
- 経営サマリーの「1症例あたり材料償還額(症例構成調整)」は、処置ごとの他4施設中央値の単価をA病院の処置別症例数で加重した「他施設並みの場合」と比較し、その差を年間の超過コストとして示します。
- 経営サマリーの金額は対象期間の実績を年換算した値です。購入価格データが無いため、償還差益の改善効果は「材料償還額 × 改善幅(想定)」で示しています。破棄・破損損失は償還対象材料のみ(償還対象外の消耗品は価格情報が無いため含みません)。使用量の差による金額は、償還対象材料のため収益も連動する参考値です。
- ファンネルプロットの管理限界は「5施設の症例数加重平均 ± z × SD/√症例数」(z=1.96/3.09)で、SDはA病院の症例間標準偏差を全施設に適用しています。
- 施設プロフィール(病床数・機能区分等)は、一般的な病床機能報告のカテゴリを参考にした想定値(イメージ)です。
- 2025年1〜12月のPCI(待機的・緊急)・ペースメーカー・ICD・CRT-P症例は、患者単位の現実的な材料構成を想定して追加したものです(`tools/add_2025_cases.js`、固定シードで再現可能)。同日に複数症例があるため症例番号(cid)を付与しています。PCIはアクセス部位・病変(CTO・高度石灰化)・血管内イメージング・ステント本数等に応じて特定保険医療材料を構成し、それ以外の消耗品は2026年の同種症例から複製しています。植込みデバイスは本体とリードのメーカーを揃え、リードレスペースメーカ・皮下植込型除細動器(S-ICD)を含みます。追加製品の償還価格は本データセットの価格水準に合わせた模擬値です。
- データの収録範囲は処置により異なります(PCI: 2025〜2026年、ペースメーカー・ICD・CRT: 2023〜2025年、アブレーション: 2023〜2026年)。2023〜2024年の植込みデバイスと2026年のPCIは、日付×処置内容単位の元データのままで、患者単位には再構成していません。
- 年を指定した他施設ベンチマークでは、施設B〜Eの値は「全期間のA病院に対する比率」を対象年のA病院の値に適用して算出します(症例数もA病院の年次変動を同率で反映)。施設プロフィール・処置構成比・類似度・メーカー浸透度は全期間の値です。
- 「推定症例数」は症例日と処置内容の組み合わせ(2025年のPCI・植込みデバイスは症例番号を含む)から推定した参考値です。
