# カテーテル室 医療材料ダッシュボード

循環器内科カテーテル室で使用される医療材料の使用実績データ(模擬)を可視化するダッシュボードです。オフラインで動作する単一ページアプリケーション(HTML/CSS/JavaScript、外部通信なし)として実装しています。

## 公開ページ

GitHub Pagesで公開しています。`index.html` を開くと閲覧できます。

## 構成

- `index.html` — ページ本体(5タブ構成のUI)
- `app.js` — 集計・描画ロジック(Chart.js使用)
- `data.js` — 集計済みデータ(ビルド成果物。元データから生成)
- `tools/rebuild_ablation_cases.js` — アブレーション症例を患者単位の現実的な構成で再生成し、派生集計を再計算するスクリプト
- `tools/add_device_benchmark.js` — 施設B〜Eのデバイス方式構成を生成するための施設プロファイル(係数)を data.js に書き込むスクリプト
- `chart.umd.min.js` — [Chart.js](https://www.chartjs.org/)(MITライセンス、ローカル同梱)

## タブ構成

1. **データ概観** — データベースに含まれる症例数・処置内訳・在庫区分・メーカー内訳などの記述統計。処置内容フィルター付き。
2. **他施設ベンチマーク** — 自施設(A病院)と、統計的に生成した模擬5施設(B〜E病院)との比較。1症例あたり材料償還額・機材点数・症例構成比の比較、自施設のポジショニング表示、類似施設の判定、主要デバイスの多様性(方式構成・採用製品数)の施設間比較。
3. **ディーラー・メーカー市場戦略** — メーカー別シェア、月別取扱額推移、施設別メーカー浸透度、材料カテゴリ別の市場集中度(HHI)分析。処置内容フィルター付き。
4. **在庫情報** — RFID棚在庫を模したアイテム別の在庫状況(定数・現在庫・充足率・週間使用予測・欠品リスク)。
5. **デバイス多様性** — 同じ用途のデバイスの方式別の使い分け(例: アブレーションカテーテルの高周波/クライオバルーン/ホットバルーン/パルスフィールド)を、構成比・四半期推移・製品一覧で表示。方式は品名・規格から自動分類し、自施設で実績のない主な方式も「実績なし」として表示。

## 重要な注意事項

- 本ダッシュボードのデータは、自施設(A病院)分を含めすべて**模擬データ**です。実在の医療機関・患者の情報ではありません。
- 「他施設ベンチマーク」の施設B〜E、および「在庫情報」の在庫数量・週間予測は、A病院のデータを統計的に加工して生成しています。
- アブレーション症例(2023年1月〜2026年3月)は、患者単位の現実的なカテーテル構成を想定して生成したものです(`tools/rebuild_ablation_cases.js`、固定シードで再現可能)。1症例日=患者1人とし、適応(心房細動・発作性上室頻拍・心房粗動・心室頻拍等)と治療方式(高周波/クライオバルーン/ホットバルーン/パルスフィールド)に応じて、3Dマッピングシステム(CARTO/EnSite)と対応する診断カテーテル・シース類を割り当てています。治療用カテーテルは1本が基本で、バルーン・PFA症例の一部のみ高周波カテーテルで追加焼灼を行います。PFAは2024年10月以降に導入され、比率が段階的に上昇する想定です。追加製品の償還価格は本データセットの価格水準に合わせた模擬値です。
- 「他施設ベンチマーク」の主要デバイスの多様性比較では、施設B〜Eの方式構成・採用製品数は、A病院の実績に施設特性(大学病院・心臓血管センター等)を反映した係数を適用して算出した模擬値です(係数は `tools/add_device_benchmark.js`)。
- アブレーションの1症例あたり材料償還額(施設B〜E)は、アブレーションカテーテルの方式構成と整合するよう画面側で算出しています: 「カテーテル以外の材料費(A病院と同水準と仮定)+ カテーテル本数/症例(A病院と同じ)× 方式構成で加重した平均単価(方式別単価はA病院の実績平均)」。高額な方式(PFA等)の比率が高い施設ほど償還額が高くなります。
- 施設プロフィール(病床数・機能区分等)は、一般的な病床機能報告のカテゴリを参考にした想定値(イメージ)です。
- 「推定症例数」は患者単位の識別IDが元データに含まれないため、症例日と処置内容の組み合わせから簡易推定した参考値です。
